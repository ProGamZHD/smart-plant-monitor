The tank is out of this picture. An ultrasonic sensor measures how full it is.

The board decides.

When the soil reads under 30% three times in a row, the board runs nine checks. Among them:

  • Soil under 30%, three readings running
  • Water left in the tank
  • 60 seconds since the last run
  • Fewer than 6 runs today

It waters for 5 seconds.

No internet is needed. The cloud can ask for water, and the board may refuse.

      Can you trust what the AI tells you?

      Gemini writes the plant's daily notes, but it is not trusted with numbers. Before a note is stored, a checker looks for every number in it among the recorded measurements Gemini was given. Try it on the evidence for 29 Oct 2026.

        Three times a day and once a week, SmartPlantReport freezes an evidence pack and asks Gemini to explain it. A draft that fails the check gets one repair attempt. If it still fails, it is stored marked as unchecked, with the missing numbers listed. Gemini decides the wording: what matters today and what to watch. It does not run the pump, does not produce a forecast, and nothing it writes reaches the board.

        The checker is the same rule set as the deployed one, running in your browser. It skips whole numbers up to 31, clock times, written dates, and 0, 7, 24, 100, 365 and 1000, and it skips any sentence tagged as coming from a web search. The example statements were written for this page. No real Gemini note is shown.

        Before you rely on these

        • The soil forecast has no established accuracy. Each retrain is scored against "no change". In this replay that score ranged from −0.45 to +0.18, and the code used the forecast only while it stayed above zero.
        • The method replay used the first export, which holds soil and temperature only. So 6 of the forecast's 14 inputs carried no information, and the tank trend had nothing to fit. The humidity, light and tank charts come from a second export and have not been run through the methods.
        • The soil probe has not yet been calibrated in its final pot.
        • The checker skips whole numbers up to 31 and clock times, and its verdict is stored with each note but not yet shown beside it on the dashboard.
        • These results come from an offline run of the deployed code, not from the values the live system stored at the time.
